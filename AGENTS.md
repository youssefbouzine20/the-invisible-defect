# Project workflow

## Maintain the progress log

- Update `docs/project_progress.md` in the same turn whenever project work changes a deliverable, experiment decision, verified result, blocker, or next step. Update the log as part of the task.
- Review relevant saved results when resuming a project step. Use the user's terminal or notebook output and saved run reports as evidence. Keep proposed settings, pending checks, and verified results clearly labeled.
- Update the relevant milestone, evidence, and next-step checklist in place. Include the date, measured values, and a relative path or command when they help reproduce the result or write the final report.

## Work with Youssef

- Work one step at a time. Give terminal commands for Git Bash. Youssef runs the commands, tests, audits, and notebook cells, and we verify the results together before moving on.
